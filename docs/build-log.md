# Build Log — Completed Units

What was built in each completed unit. See [CLAUDE.md](../CLAUDE.md) for the build sequence table and unit goals.

---

**Unit 0** — `docker-compose.yml` (Postgres 16 on 5433, Redis 7, API on 8001, Celery worker), `app/main.py` (`GET /health`, `POST /health/worker`), `app/tasks.py` (`ping` task).

**Unit 1** — `app/db/enums.py` (`BookStatus` + `LEGAL_TRANSITIONS` + `assert_legal_transition`), `app/db/models.py` (all 6 tables), `app/db/repos/` (one class per table), `migrations/versions/0002_schema.py`.

**Unit 2** — `app/providers/base.py` (`LLMProvider`, `ImageProvider` ABCs; `LLMResponse`, `CharacterRef`, `ImageResult` dataclasses), `app/providers/fake_llm.py` (`FakeLLMProvider` — injectable response queue, records calls), `app/providers/fake_image.py` (`FakeImageProvider`), `app/providers/factory.py` (`get_llm_provider` / `get_image_provider` driven by `Settings.llm_provider` / `Settings.image_provider`, both default to `"fake"`).

**Unit 3** — `app/agents/writer.py` (`WriterAgent.write(brief, method, prior_critique)` — 4 named methods, revision vs. fresh system prompts), `app/agents/judge.py` (`JudgeAgent.judge(story_versions, criteria)` — one LLM call per version, 3-retry loop with error fed back to LLM, `PROMPT_VERSION = "v1"`), `app/agents/base.py` (`JudgementResult`, `validate_judgement_json` — computes `passed` from threshold, not LLM opinion).

**Unit 5** — `app/events.py` (`publish_event` — sync Redis pub/sub; silently swallows errors so events never break the pipeline), `app/storage/local.py` (pre-existing gap: `LocalStorage` backing the dev storage seam), `app/api/__init__.py` + `app/api/books.py` (router: `POST /books`, `GET /books`, `GET /books/{id}`, `GET /books/{id}/versions`, `POST /books/{id}/approve`, `POST /books/{id}/reject`, `POST /books/{id}/retry`, `WS /books/{id}/stream`), `app/main.py` (mounts books router), `app/db/enums.py` (`AWAITING_APPROVAL` gains `REVISION` as a legal target for human rejection), `app/db/repos/book.py` (`list_all()`), `app/db/repos/story_version.py` (`list_for_book()`), `app/tasks.py` (all three pipeline tasks now call `_emit()` after each step, publishing a `status_change` event to Redis). Approve advances AWAITING_APPROVAL → APPROVED synchronously; reject sends AWAITING_APPROVAL → REVISION and re-enqueues `pipeline_handle_revision`; retry re-enqueues the right task for JUDGING or REVISION.

**Unit 6** — `app/providers/deepseek_llm.py` (`DeepSeekLLMProvider` — OpenAI-compatible client pointed at `https://api.deepseek.com`; streams via `client.chat.completions.stream()` + `.get_final_completion()`; routes writer calls to `deepseek-v4-pro` and judge calls to `deepseek-v4-flash` using `json_schema is not None` as discriminator; `max_tokens` 8192 writer / 1024 judge), `app/providers/factory.py` (adds `"deepseek"` branch with lazy import so fake-provider tests never require the SDK), `pyproject.toml` (`openai>=1.0` dependency), `.env.example` (`LLM_PROVIDER` + `DEEPSEEK_API_KEY` documented). Zero changes to agents or orchestrator. 145 tests, all passing offline.

**Unit 7 (partial)** — `app/providers/placeholder_image.py` (`PlaceholderImageProvider` — uses Pillow to generate labeled JPEG rectangles at exact 300 DPI spread dimensions from the book design spec; reads `params["spread_type"]` to select dimensions; renders prompt text and character_ref on a steel-blue-header / gray-body canvas; saves to `LocalStorage`; returns `ImageResult`). `app/providers/factory.py` gains `"placeholder"` branch with lazy import. `pyproject.toml` adds `pillow>=10.0`. `IMAGE_PROVIDER=placeholder` documented in `.env.example`. When Leonardo key arrives: add `LeonardoImageProvider`, set `IMAGE_PROVIDER=leonardo`, re-run `GENERATING_IMAGES` — no other code changes. 166 tests, all passing. Spread dimensions: `FULL_BLEED_DOUBLE` 5175×2625, single-page spreads 2625×2625, `PORTRAIT_WITH_CAPTION_BELOW` 2625×1838, `VIGNETTE` 1838×1838.

**Unit 8** — `app/compositor/` (8 modules): `spread_types.py` (`SpreadType` enum + `assign_spread_types()` — 12-spread narrative-position assignment per spec), `typography.py` (Andika + Fredoka One font registration; `body_font_size`, `wrap_text`, `contrast_ratio`, `pick_text_color`, `needs_contrast_pill`), `color.py` (RGB→CMYK with bundled SWOP TR005 ICC profile via Pillow `ImageCms`), `page_renderer.py` (`render_spread` — 5 spread types with WCAG AA contrast-pill logic), `cover_renderer.py` (`render_cover` — flat cover PDF: back + spine at 0.002252"/page + front with KDP barcode zone), `pdf_writer.py` (`assemble_interior` — 32-page interior per spec page structure; `_split_story` distributes paragraphs to 12 spreads), `composer.py` (`BookComposer.compose_all` — interior PDF, cover PDF, Word .docx, Markdown, plain text, images folder; all keys returned in export manifest), `fake_compositor.py` (`FakeComposer` — structurally valid PDFs via colored rectangles; same interface, used in all tests). Fonts bundled: `Andika-Regular.ttf`, `Andika-Bold.ttf`, `FredokaOne-Regular.ttf` in `app/compositor/fonts/`. ICC profile: `USWebCoatedSWOP.icc` in `app/compositor/icc/`. `app/agents/metadata.py` (`MetadataAgent.draft(story_text, brief)` — JSON-schema-validated LLM call producing title/subtitle/author/description/keywords/age_range/series_name; 3-retry loop with error feedback). `migrations/versions/0003_book_metadata_export.py` (adds `book_metadata` JSONB + `export_manifest` JSONB to `books`). `app/db/repos/book.py` gains `save_metadata` + `save_export_manifest`. `app/orchestrator.py` gains `generate_images` (APPROVED→GENERATING_IMAGES→GENERATING_COVER; 12 scene image rows, event callback for progress), `generate_cover` (GENERATING_COVER→DRAFTING_METADATA; 1 cover image row), `draft_metadata` (DRAFTING_METADATA→EXPORTING; saves LLM-drafted metadata to book), `export_book` (EXPORTING→EXPORT_READY; calls `BookComposer.compose_all`, saves manifest; graceful None for missing image files). `app/tasks.py` gains `pipeline_generate_images`, `pipeline_generate_cover`, `pipeline_draft_metadata`, `pipeline_export` — chained Celery tasks; `_make_orchestrator` now passes `ImageRepo` + `LocalStorage`. `app/api/books.py`: `approve_book` now triggers `pipeline_generate_images.delay()`; adds `GET/PUT /books/{id}/metadata` (merge-patch semantics), `GET /books/{id}/export` (manifest), `GET /books/{id}/export/{artifact}` (download with correct MIME type). `pyproject.toml` adds `reportlab>=4.0`, `fonttools>=4.0`, `python-docx>=1.1`. `tests/test_unit4.py` gains `_FakeImageRepo` + `_FakeStorage` + updated `_make_env` signature. 225 tests, all passing.

**Unit 9** — `frontend/` (Next.js 15 + React 19 + Tailwind 3): dark-theme dashboard talking only to the FastAPI backend. `app/page.tsx` — Kanban board: polls `GET /books` every 8 s; priority queue section floats all `AWAITING_APPROVAL` books to the top with a blue pulsing border; remaining books grouped into four columns (In Progress / Draft / Complete / Retired), each card colored by status (yellow = running, blue = approval gate, green = done, red = retired). "New Book" modal calls `POST /books` with title, description, characters, setting, age-range, theme, max_rounds, and score_threshold fields. `app/books/[id]/page.tsx` — detail page: meta row (status, round, threshold, updated), `AWAITING_APPROVAL` gate with Approve / Reject (+ optional rejection note), latest-round story variants sorted by judge score (best variant labeled), per-variant judge score breakdown (5 dimensions with bar charts + expandable critique text), inline paragraph editor (click any paragraph → ParagraphEditor modal), metadata editor and export download panel for `EXPORT_READY`/`DONE` books, live WebSocket event feed (connects to `WS /books/{id}/stream`, re-fetches book + versions on every `status_change` event). `components/ParagraphEditor.tsx` — modal: shows original paragraph, instruction textarea (⌘↵ shortcut), calls `POST /books/{id}/paragraphs/rewrite`, displays before/after side-by-side. Backend additions: CORS middleware in `app/main.py` (allows `localhost:3000`); `POST /books/{book_id}/paragraphs/rewrite` endpoint in `app/api/books.py` — verifies book exists, calls `get_llm_provider().generate()`, returns `{original, rewritten}`. `lib/api.ts` uses `NEXT_PUBLIC_API_URL`; `lib/hooks.ts` provides `usePolling` (interval refresh) and `useBookStream` (WebSocket). Copy `frontend/.env.local.example` → `frontend/.env.local` and run `cd frontend && npm install && npm run dev`. 229 tests, all passing.
